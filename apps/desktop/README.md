# ProjectTrack desktop shell (P02 / UI-01)

This is the executable React/Vite shell for the approved UI-01 gate. It contains navigation, ribbon, deterministic fixture views and view-state affordances only. Scheduler, resource calculations, persistence and later phase behavior are intentionally outside this packet.

Run locally:

```text
npm install
npx vite --host 127.0.0.1 --port 4173
```
