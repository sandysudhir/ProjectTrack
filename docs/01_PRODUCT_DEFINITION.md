# Product Definition

ProjectTrack is a Windows desktop scheduling environment combining a spreadsheet, graphical timeline, scheduling engine, resource/cost model, tracking system, reporting canvas and native multi-project workspace.

## User outcomes

A user must be able to build a detailed individual project, compact any branch to a meaningful summary row, and open an All Projects tab where every project is visible on one shared timeline. Any project can be expanded in place down to phases, activities, sub-activities and individual bars. The user can also expand every project into one continuous scrollable sequence and see current work across the organisation.

## Workflow-equivalence target

Recreate the important FastTrack-class workflows evidenced in the source ledger and screenshots without copying proprietary code, assets, branding or pixel-level appearance. When exact source behavior is unknown, label it open and obtain evidence or make an explicit approved ProjectTrack decision.

## Product priorities

1. correct domain model;
2. scheduling correctness;
3. Scheduled/Revised/Actual/Baseline integrity;
4. interaction speed and precision;
5. data integrity and recovery;
6. All Projects workflow;
7. resource/cost correctness;
8. view/report persistence;
9. visual polish.

## Target platform and scale

Windows 11 desktop. Design for 10,000 rows, 15,000 bars, 25,000 dependencies, 2,000 resources and 50,000 assignments.

## V1 non-goals

Cloud collaboration, account/billing systems, arbitrary scripting, AI scheduling, Monte Carlo simulation, PERT, Kanban, automatic leveling and unreliable native MPP parsing.
