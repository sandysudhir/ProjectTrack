# UI-01R Target Visual Specification

ProjectTrack uses an original light professional desktop language grounded in the screenshot evidence: blue Windows-style chrome, dense ribbon command groups, pale engineering grids, compact typography, and a persistent status bar. The app keeps its own ProjectTrack mark and fixture data.

The working shell has a title/quick-access region, project tabs, contextual ribbon, left project/view navigation, a split Schedule grid/timeline, structured Resource and Calendar views, shell dialogs/inspectors, and horizontal/vertical density controls. Schedule evidence renders 34 fixture rows in expanded mode and retains stable top-level rows in compact mode.

All screenshot-confirmed commands have a visible location. Actions that belong to later gates stay disabled and expose `Available after UI-03 / G-ENG-02`. Shell actions open reusable dialog inventories populated with presentation fixture values; they do not claim domain calculations.

Acceptance for UI-01R is visual and structural: all 41 original screenshots are mapped, all 52 manifest files are reviewed, the integrated shell is captured at 1440×900 and 1920×1080, Schedule/Resource/Calendar and ribbon switching work, compact/expanded state works, and no later-phase engine is introduced.
